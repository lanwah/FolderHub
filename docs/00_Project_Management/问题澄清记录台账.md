## V2.6.1 四维状态模型与决策分级适配（2026-11-14）
本节自同步日起适用于新提出或重新处理的澄清事项；历史条目保持原样，不追溯性重写。

- D1：重大决策，必须用户明确确认；未确认时仅阻断受其影响的工作/交付/基线。
- D2：重要决策，按批次集中提问；允许延期，但须记录原因、影响、责任方、触发条件、临时防护和重审节点。
- D3：低风险、可逆且可可靠推导的普通细节；不主动向用户提问、不创建 Q/CLQ，在相应需求/设计/假设记录中披露来源、依据、影响及验证方式。
- 无法可靠判级时标记待判级，采取保守措施，不得直接降为 D3。
- 对每项实际提出的 D1/D2 问题，分别记录四个维度：
  1. 记录完整性：澄清全过程证据是否完整；
  2. 决策完成度：是否取得明确且范围清晰的用户确认/拒绝；
  3. 阶段阻塞性：未决事项影响哪些工作、交付或基线；
  4. 延期有效性：延期原因、影响、责任方、触发条件、临时防护和重审节点是否齐备。
- 四维结论彼此独立；记录完整不等于决策完成，决策未完成不必然阻断无依赖工作，延期有效不等于用户接受。
- RAW/Q/ADR/CR/阶段状态保留各自原有状态枚举；决策处理状态单独记录。
- Q-015、Q-026 及 Q-029～Q-150 的历史状态/证据边界本次均不改写；后续重新处理时按新规范评估。
