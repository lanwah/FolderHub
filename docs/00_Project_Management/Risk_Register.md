# FolderHub 风险台账（Risk Register）

- 项目名称：FolderHub
- 台账版本：1.2
- 最后更新：2026-11-05
- 权威性：本台账是项目风险识别、评估、应对和状态的唯一权威记录。
- 初始化说明：本台账已登记 RISK-001；风险评估为基于当前范围与验证证据的初步定性判断，后续需随 Q-019/Q-020 已确认范围及 P3 技术验证结果复核。

## 1. 使用规则
- 风险编号使用 `RISK-001` 起的全局唯一递增编号，废弃编号不得复用。
- 风险描述尚未发生但可能影响项目目标的不确定事件；已发生的问题应同时关联问题/缺陷/CR。
- 概率和影响采用低/中/高定性等级，并填写判断依据；无依据时不得伪造评估。
- 每项风险记录应包含应对措施、责任人（未知时写“待分配”）、状态、复查日期/触发条件及关联事项。
- 用户接受风险必须保留明确的用户接受表达、范围和日期；助手建议不构成风险接受。
- 关闭风险时追加关闭依据，不删除历史。

## 3. 状态定义
- `OPEN`：已识别，尚未开始应对。
- `MITIGATING`：正在执行规避、缓解或转移措施。
- `ACCEPTED`：用户明确接受剩余风险，必须有批准证据、范围和日期。
- `OCCURRED`：风险事件已发生，必须关联后续处置记录。
- `CLOSED`：风险已消除、失效或经证据确认不再适用，必须记录关闭依据。
