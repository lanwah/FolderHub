| ADR-007 | 单个文件夹独立桌面组件 | 每个文件夹可单独开启独立桌面卡片，默认关闭；卡片显示图标、名称和用途说明；不依赖主组件显示；允许多个卡片同时存在；每个卡片可独立调整位置并锁定位置 | CONFIRMED | RAW-013 |

| ADR-009 | 文件夹分类归属 | 同一文件夹允许同时属于多个分类 | CONFIRMED | RAW-002 |
| ADR-010 | 分类/文件夹管理操作 | 分类和文件夹均支持新增、编辑、删除、手动排序；删除分类时关联文件夹移至“未分类”；删除文件夹记录仅移除 FolderHub 登记，不删除磁盘真实目录 | CONFIRMED | RAW-002 |
| ADR-011 | 添加文件夹交互 | 支持从 Windows 资源管理器拖拽文件夹到 FolderHub 添加 | CONFIRMED | RAW-002/RAW-005 |
| ADR-012 | 主组件启动显示状态 | 启动后主组件默认隐藏，仅托盘常驻，用户可从托盘打开；托盘菜单包含“打开主界面”“设置”“退出应用” | CONFIRMED | RAW-010 |
| ADR-013 | 主组件桌面位置锁定 | 固定到桌面控制显示；未锁定可拖动/调整，锁定后禁止移动/调整；主组件位置和锁定状态跨应用重启保存 | CONFIRMED | RAW-011 |
| ADR-014 | 桌面组件透明度 | 20%～100%，默认 88%；仅背景透明，文字/图标不透明；滑块实时预览并自动保存 | CONFIRMED | RAW-012 |
| ADR-015 | 首版搜索范围 | 首版支持名称/别名搜索，不支持高级筛选 | CONFIRMED | RAW-001 |
| ADR-016 | 同类项目调研深度 | 轻量调研 5～10 个候选项目并进行基本技术可行性验证；交付项目对比表、可复用性分析、许可证/活跃度风险、技术路线建议及待验证清单；不代表批准特定技术栈 | CONFIRMED | RAW-001 |
| ADR-017 | 文件夹别名规则 | 每条文件夹记录支持一个可选别名；列表优先显示别名，未设置时显示真实名称；搜索匹配别名和真实名称；别名允许重复 | CONFIRMED | RAW-003 |
| ADR-018 | 文件夹用途说明规则 | 用途说明为可选字段，在新增/编辑界面维护；主组件列表和独立卡片均显示；长内容截断并可通过详情或悬停查看完整内容；不设严格字数限制 | CONFIRMED | RAW-004 |
| ADR-019 | 文件夹路径不可用处理 | 路径不可用时保留 FolderHub 记录并标记异常，允许重新指定路径；不自动删除记录或磁盘目录；主要在用户打开时检查，恢复连接后可重新访问 | CONFIRMED | RAW-005 |
| ADR-020 | 文件夹打开交互 | 主组件列表和独立卡片双击打开；单击仅选中；右键菜单提供“打开文件夹”；调用 Windows 默认文件资源管理器；路径不可用时提示 | CONFIRMED | RAW-006 |
| ADR-021 | 主程序退出后独立卡片保留设置 | 采用全局统一设置，不提供逐卡片覆盖；默认开启。开启时退出主程序后独立卡片继续显示；关闭时退出主程序后所有独立卡片一并关闭。具体生命周期技术实现留待 P3 设计评估 | CONFIRMED | RAW-013/Q-010 |
| ADR-022 | Windows Server 单用户桌面支持 | 首版保留 Windows 10（22H2）/Windows 11（x64）本地交互式桌面支持，并增加 Windows Server 单用户交互式桌面支持；不包含 RDS 多用户 | CONFIRMED | RAW-001/Q-016/CR-001 |
| ADR-023 | 分类层级 | 分类采用平级列表，不支持父子分类或嵌套 | CONFIRMED | RAW-002/Q-017 |
| ADR-024 | 分类内文件夹排序 | 每个分类独立维护文件夹手动顺序；同一文件夹在不同分类中可以处于不同位置 | CONFIRMED | RAW-002/Q-018 |
| ADR-025 | Windows Server 版本范围 | 首版支持 Windows Server 2012 及以上版本的单用户交互式桌面环境；不包含 RDS 多用户 | CONFIRMED | RAW-001/Q-019/CR-001 |
| ADR-026 | Windows Server 安装形态 | Windows Server 2012/2012 R2 使用 Server with a GUI；Windows Server 2016 及以上使用 Desktop Experience；不支持 Server Core | CONFIRMED | RAW-001/Q-020/CR-001 |
