## 1. 问题与背景

Q-016 已确认首版增加 Windows Server 单用户交互式桌面支持，但用户尚未指定 Server 版本。FolderHub 需要桌面交互、系统托盘和桌面组件，因此本问题同时限定为带桌面体验（Desktop Experience）的安装，不默认包含 Server Core。具体兼容性仍需技术验证。

微软当前资料显示 Windows Server 2025 是当前 LTSC 版本；Windows Server 2022 的主流支持已于 2026-10-13 结束、扩展支持持续至 2031-10-14；Windows Server 2025 扩展支持至 2034-11-14。来源：Microsoft Learn Windows Server release information 与生命周期页面。

官方依据： [Windows Server release information](https://learn.microsoft.com/en-us/windows/release-health/windows-server-release-info)；[Windows Server 2025 lifecycle](https://learn.microsoft.com/en-us/lifecycle/products/windows-server-2025)；[Windows Server 2022 lifecycle](https://learn.microsoft.com/en-us/lifecycle/products/windows-server-2022)。\n\n## 2. 本轮选项

| 选项 | 完整含义 | 优点 | 缺点/代价/风险 |
|---|---|---|---|
| A | 仅支持 Windows Server 2025（Desktop Experience）单用户交互式桌面 | 测试矩阵最小；目标聚焦当前 LTSC 版本 | 不覆盖仍在使用 Server 2022 的环境 |
| B | 支持 Windows Server 2022 和 2025（均为 Desktop Experience）单用户交互式桌面 | 覆盖当前与上一代常见 LTSC 部署；兼顾较新版本和现有环境 | 比仅支持 2025 增加一组兼容验证 |
| C | 支持 Windows Server 2019、2022 和 2025（均为 Desktop Experience）单用户交互式桌面 | 覆盖面更广，照顾仍在使用 2019 的环境 | 增加旧版本适配和回归成本；Server 2019 生命周期较短 |
| D（其他） | 自定义 Windows Server 版本、版本版次/Edition 或安装选项 | 可准确匹配实际部署环境 | 需要进一步核对与验证 |

## 3. 助手推荐

**推荐：B（中置信度）。** Windows Server 2025 是当前 LTSC 版本；Server 2022 虽已结束主流支持，但仍处于扩展支持周期。将 2022/2025 纳入首版，通常能在覆盖现有部署与控制测试成本之间取得平衡。若实际部署只使用最新系统，A 更精简；若明确存在 Server 2019 环境，再考虑 C。

可能改变推荐的因素：用户实际部署的 Server 版本、组织升级周期、是否必须兼容旧版系统。

## 4. 用户回答

用户回答原文（VERBATIM）：`Q-019：D:Windows Server 2012及以上版本`

最终确认：首版支持 Windows Server 2012 及以上版本的单用户交互式桌面环境。具体安装形态由 Q-020 进一步确认。Q-019 CLOSED / CONFIRMED。

## 5. 既有确认保护

本问题只细化 Q-016 已确认的 Windows Server 单用户交互式桌面支持范围，不改变 Windows 10（22H2）/Windows 11（x64）支持，不增加 RDS 多用户支持，也不改变 RAW-002 相关决策。
