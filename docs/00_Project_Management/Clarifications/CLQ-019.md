## 1. 问题与背景

FolderHub 需要桌面组件、系统托盘和图形交互，因此需明确 Server Core 是否纳入支持。Server 2012/2012 R2 与 Server 2016 之后的安装选项命名不同，必须分别记录。

## 2. 本轮选项

| 选项 | 完整含义 | 优点 | 缺点/代价/风险 |
|---|---|---|---|
| A（推荐） | Server 2012/2012 R2 使用 Server with a GUI；Server 2016 及以上使用 Desktop Experience；不支持 Server Core | 与桌面组件、托盘和图形交互的产品形态一致；支持边界明确 | 不覆盖无图形桌面的 Server Core |
| B | 同时支持 GUI/Desktop Experience 与 Server Core | 覆盖面更广 | Server Core 缺少常规桌面交互，需要另一套操作/管理体验，显著增加范围 |
| C | 首版只支持 Server 2022/2025 Desktop Experience，旧版暂缓 | 测试矩阵较小 | 与用户已确认的 Server 2012+ 版本范围冲突，若选择需另走变更 |
| D（其他） | 自定义安装形态 | 可按部署环境定义 | 需进一步拆分和评估 |

## 3. 助手推荐

**推荐：A（高置信度）。** FolderHub 是桌面交互式工具，Server Core 不具备与完整桌面环境相同的交互基础；A 与已确认的产品形态匹配。

## 4. 用户回答

用户回答原文（VERBATIM）：`Q-020：A`

最终确认：
- Windows Server 2012 / 2012 R2：支持 Server with a GUI。
- Windows Server 2016 及以上：支持 Desktop Experience。
- 不支持 Server Core。
- 不包含 RDS 多用户环境。
- 兼容性仍需逐版本验证。
