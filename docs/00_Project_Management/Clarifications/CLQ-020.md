# CLQ-020：主组件首次安装时固定到桌面的默认值

- 关联问题：Q-022
- 关联需求：RAW-011
- 关联决策：ADR-005、ADR-013（既有行为）；ADR-027（本次新增确认）
- 阶段：P2_REQUIREMENT_ANALYSIS
- 状态：CLOSED / CONFIRMED
- 记录版本：V1.1
- 创建日期：2026-11-10
- 最后更新：2026-11-11
- 来源：P2 SRS 分析发现既有确认内容明确了“可配置固定到桌面”，但未明确首次安装默认值。

## 1. 问题与背景

已确认主组件可配置是否固定到桌面；未锁定时可移动/调整，锁定后禁止移动/调整；主组件位置和锁定状态跨应用重启保存。此处的“首次安装默认固定状态”尚无用户确认记录。

该问题与“启动后主组件默认隐藏、托盘常驻”是两个不同设置，不改变 ADR-012 的启动显示行为。

## 2. 本轮选项

| 选项 | 完整含义 | 优点 | 缺点/代价/风险 |
|---|---|---|---|
| A（推荐） | 首次安装默认不固定到桌面；用户可从主界面/设置主动开启 | 初次安装不直接改变桌面布局；与独立卡片默认关闭的现有规则更一致；减少意外遮挡 | 用户首次使用需手动开启桌面固定 |
| B | 首次安装默认固定到桌面 | 首次启动即可体现桌面组件形态 | 可能遮挡桌面内容；与主组件启动默认隐藏的理解容易混淆；首次安装侵入性更高 |
| C | 首次运行时询问用户是否固定到桌面 | 明确交由用户决定 | 增加首次运行步骤和设置流程 |
| D（其他） | 用户自定义默认行为 | 可覆盖其他实际使用习惯 | 需要进一步描述具体规则 |

## 3. 助手推荐

**推荐：A（中置信度）。**

依据：
- 用户已明确主组件固定显示是可配置项，并未要求首次安装自动显示。
- 主组件启动默认隐藏，独立卡片默认关闭；默认不固定可以避免首次安装即占用桌面。
- 该选择仅是默认值，不影响用户之后启用固定显示。

未知信息：用户是否希望安装后立即看到主组件桌面组件。若用户明确希望首次安装即展示，B 或 C 更合适。
