# CLQ-015：FolderHub 首版目标运行环境与使用场景

- 关联问题：Q-016
- 关联需求：RAW-001
- 阶段：P1_REQUIREMENT_COLLECTION
- 状态：CLOSED / CONFIRMED
- 记录版本：V1.1
- 日期：2026-11-04
- 来源：本轮对 RAW-001 的需求完整性检查；以下选项均为本轮新澄清，不冒充历史选项。

## 1. 问题与背景

已确认的操作系统支持范围为 Windows 10（22H2）和 Windows 11（x64）（Q-001 / ADR-008）。但项目早期问题描述提到 Windows Server 环境，项目章程中的目标用户和实际使用场景仍未明确。需要确认首版实际面向的运行环境，避免把“操作系统支持范围”与“远程使用场景”混为一谈。

## 2. 本轮选项

| 选项 | 完整含义 | 优点 | 缺点/代价/风险 |
|---|---|---|---|
| A | 首版面向 Windows 10（22H2）/Windows 11（x64）的本地交互式桌面用户；不承诺 Windows Server 操作系统兼容，也不把多用户 RDS 作为首版目标 | 与 Q-001 / ADR-008 已确认范围一致；桌面壁纸层、托盘、开机启动等场景清晰，验证范围较可控 | 不覆盖 Windows Server 原生运行及 RDS 多用户隔离场景 |
| B | 仍以已确认的 Windows 10/11 为支持平台，但要求在远程桌面/远程控制会话中也能正常使用（单个交互用户会话） | 适用于远程管理个人电脑的使用方式，不必立即扩大操作系统支持范围 | 需额外验证远程会话下桌面组件、托盘和窗口层级行为 |
| C | 首版还需支持 Windows Server 的单用户交互式桌面运行（不要求多用户 RDS） | 覆盖服务器控制台/单用户桌面使用 | 会扩大 Q-001 / ADR-008 当前确认的操作系统范围，需先做变更影响评估和兼容验证 |
| D | 首版同时支持 Windows Server Remote Desktop Services（RDS）多用户环境，各登录用户的配置、托盘和桌面卡片彼此隔离 | 覆盖多用户服务器部署场景 | 范围和验证成本明显增加；需处理用户会话隔离、配置隔离、启动生命周期和权限等问题，并重新评估 Q-001 / ADR-008 |
| E（其他） | 以上均不符合；请自定义描述目标操作系统、登录方式、用户数量及部署方式 | 可精确描述实际环境 | 需要进一步拆分确认 |

## 3. 助手推荐

**推荐：A（中置信度）。** 依据是用户已明确确认 Windows 10（22H2）和 Windows 11（x64）为支持范围，且 FolderHub 的主要形态依赖桌面壁纸层、系统托盘和桌面卡片。历史问题描述曾提及 Windows Server，因此仍需用户确认实际目标环境；若实际部署在 Server/RDS，应选择 C/D 或 E，并对既有 ADR-008 进行正式影响评估，不会因本次选择自动覆盖原决策。

可能改变推荐的因素：FolderHub 是否确实要安装在 Windows Server 上，是否存在多个并发登录用户，以及每个用户是否需要独立配置和桌面组件。
