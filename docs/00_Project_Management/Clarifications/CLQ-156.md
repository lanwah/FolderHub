## 2. 问题与范围

当 Main Process 仍在运行时，本会话 CardHost 异常退出，FolderHub 应采用何种恢复策略？

本问题不讨论 Main Process 已退出且 Keep Cards=ON 的情形；该情形已由 ADR-037 决定。

## 3. 候选与用户选择

用户选择 A：Main Process 负责监测 CardHost 崩溃并自动重启；采用有限重试和退避；多次失败后提示用户；不允许无限重启。

## 5. 影响与未决实现细节

- Main Process 存活期间由其进程生命周期协调逻辑承担监测与有限重启，不新增独立常驻 Supervisor/Windows Service。
- 必须避免旧宿主未退出导致重复实例；恢复过程遵守 ADR-035 单一写入者边界，并执行幂等状态对账。
- 最大重试次数、退避时长/算法、统计窗口、启动/恢复超时、最终失败状态、提示方式和人工恢复入口均未定值。
- Main Process 退出时必须停止监测与后续重启；不得留下脱离主进程的监督实体。
- 上述细节由 P3 PoC 和设计分析收敛；不得把候选参数当作用户确认。
