# CLQ-023：搜索范围（跨分类或当前分类）

- 关联问题：Q-025
- 关联需求：RAW-001、RAW-003
- 关联决策：ADR-015、ADR-017、ADR-029、ADR-030
- 阶段：P2_REQUIREMENT_ANALYSIS
- 状态：CLOSED / CONFIRMED
- 记录版本：V1.1
- 创建日期：2026-11-12
- 来源：Q-024 用户选择 A 后复核 FR-007；Q-024 确认了匹配算法和触发方式，但没有明确跨分类搜索范围。

## 1. 问题与背景

已确认首版支持按文件夹真实名称和别名搜索，采用不区分大小写的包含匹配，输入变化时动态更新；清空关键词恢复当前分类完整列表；无结果时显示明确提示。尚未明确搜索是在当前选中分类内执行，还是跨全部分类执行。

由于同一文件夹记录允许关联多个分类，跨分类搜索结果还涉及如何避免同一记录重复显示。本问题只确认搜索范围和结果呈现边界，不增加高级筛选。

## 2. 本轮选项

| 选项 | 完整含义 | 优点 | 缺点/代价/风险 |
|---|---|---|---|
| A（推荐） | 搜索全部已登记文件夹记录，不受当前选中分类限制；同一记录只显示一次，并显示其所属分类信息；清空关键词后回到当前选中分类列表 | 最符合快速查找定位；用户不必先判断文件夹属于哪个分类；与一条记录多分类关联一致 | 搜索结果需清楚表达所属分类；跨分类结果列表与普通分类列表的呈现需保持一致 |
| B | 仅搜索当前选中分类中的文件夹记录；切换分类后搜索范围随之变化 | 行为简单、结果范围明确 | 用户若不知道文件夹所属分类，可能无法找到目标 |
| C | 默认搜索当前分类，并提供一个“搜索全部分类”开关 | 兼顾局部与全局场景 | 增加一个设置/交互状态，超出最简搜索流程 |
| D（其他） | 自定义搜索范围及结果显示规则 | 可按实际习惯调整 | 需要补充完整规则 |

## 3. 助手推荐

**推荐：A（中高置信度）。**

依据：
- FolderHub 的目标是快速访问，跨分类搜索减少用户先选择分类的步骤。
- 已确认同一文件夹可以关联多个分类，且同一路径只保留一条记录；搜索结果按记录唯一显示更符合数据模型。
- 搜索无高级筛选的边界仍然保留；显示所属分类仅用于识别结果，不构成筛选能力。

未知信息：用户是否偏好只在当前分类内搜索。若选择 A，清空关键词仍恢复当前选中分类的完整列表；搜索结果则暂时跨全部分类。

确认结论：
- 搜索范围覆盖全部已登记文件夹记录，不受当前选中分类限制。
- 同一文件夹记录只在搜索结果中显示一次，不因其关联多个分类而重复显示。
- 搜索结果应显示该记录所属的分类信息，帮助用户识别其分类归属。
- 清空搜索关键词后，恢复当前选中分类的完整列表。
