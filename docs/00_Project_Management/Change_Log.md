## 变更管理规则
1. 已确认需求或已批准文档发生变化时，创建唯一 CR 编号。
2. 保留变更前内容和历史版本，不静默覆盖。
3. 分析对原始需求、正式需求、设计、接口、测试及文档的影响。
4. 未经用户明确批准，不将建议变更写入正式基线。


## CR-001 变更详情与影响分析
- 提出/确认日期：2026-11-04 至 2026-11-05。
- 用户确认依据：Q-016 最终选择组合选项 A；Q-019 原文 `Q-019：D:Windows Server 2012及以上版本`；Q-020 原文 `Q-020：A`。
- 原范围：Windows 10（22H2）/Windows 11（x64）本地交互式桌面。
- 新范围：保留原 Windows 10/11 支持；增加 Windows Server 2012 及以上单用户交互式桌面。Server 2012/2012 R2 为 Server with a GUI；2016 及以上为 Desktop Experience；不含 Server Core/RDS 多用户。
- 需求影响：RAW-001、Q-016、Q-019、Q-020。
- 决策影响：ADR-022、ADR-025、ADR-026。
- 设计/测试影响：后续 P3/P4 需评估桌面层级、托盘、启动、权限、文件系统和显示行为；测试阶段需建立覆盖目标版本的兼容性矩阵。
- 风险：RISK-001 保持 OPEN；用户确认范围不等于通过兼容性测试。
- 状态：范围已由用户明确确认；技术可行性/兼容性验证未完成。
