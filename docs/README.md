## 管理规则

1. 所有研发文档统一放在项目根目录 `docs/` 下。
2. 不将助手建议当作用户确认的需求或决策。
3. 未经用户明确批准，不进入下一研发阶段。
4. 已确认需求和批准基线不得静默修改；变更必须登记并进行影响分析。
5. 每次工作维护需求、问题、决策、变更台账和项目阶段状态。
