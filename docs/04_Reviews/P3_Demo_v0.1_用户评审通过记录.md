1. 双击独立卡片的打开动作目前为原型模拟，不会实际调用 Windows 资源管理器。

4. Q-015 独立卡片宿主生命周期仍为 OPEN / D2 / DEFERRED；Demo 不选择进程/服务架构。
5. 浏览器实际渲染、Windows 实机和 Windows Server 兼容性、Git Commit/Tag 均未在当前执行环境核验。
