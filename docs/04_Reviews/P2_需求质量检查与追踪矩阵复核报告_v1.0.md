## 4. 发现修正记录

本轮在 SRS v0.11 中修正以下草案一致性问题：

1. **Q-026 状态残留矛盾**：旧版第 8.3、10 章仍有“多显示器/DPI 恢复策略尚未定义”的文字，与 Q-026 CLOSED、ADR-033、FR-019 冲突。现改为用户可见行为已确认，具体算法留待 P3/P4。
2. **卡片尺寸/位置冲突重复列为未决**：Q-029/Q-030 已有历史摘要重建结论，现明确其已登记在第 18 章，同时保留 RECONSTRUCTED 证据等级。
3. **备份/恢复需求状态错误**：旧版第 9.2、13.3 将备份/恢复整体写为未确认，与 Q-031～Q-150 的摘要重建记录冲突。现区分产品业务规则已记录与底层存储/事务/迁移实现仍待设计。
4. **显示环境异常场景过时**：第 10 章现引用 FR-019，不再将用户已确认的恢复行为标为未定义。
5. **追踪字段不完整**：将既有业务规则编号为 BR-001～BR-012；将 UIR-001/002 正式条目化；NFR-001～004 补齐来源和优先级待评审字段。
6. **文字错误**：修正恢复记录清理顺序“旧到旧”为“旧到新”。

以上修订仅为既有用户确认语义的规范化、追踪和矛盾修正；没有修改 RAW 原文或 ADR 决策内容。
