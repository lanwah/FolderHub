# FolderHub Demo Change Log

## p3-demo-v0.1 - 深色主题切换（2026-11-22）

- 新增浅色 / 深色主题；标题栏、桌面状态栏与设置面板均可切换。
- 主题选择写入 `localStorage`（`folderhub-demo-theme`）；无记录时跟随系统 `prefers-color-scheme`。
- 深色主题覆盖窗口、侧栏、卡片、任务栏、弹层与壁纸；透明度滑块按主题 panel RGB 生效。

## p3-demo-v0.1 - 主题可读性优化（2026-11-22）

- 提高正文/次要文字对比度，统一加深 ink / muted 色阶。
- 整体字号上调（原 9–11px 次要文案改为约 11–13px），主标题与按钮更易辨认。
- 加载 DM Sans + Noto Sans SC，避免回落系统默认字体导致观感发灰。
- 壁纸改为更深、更清晰的青绿桌面底，主窗口与桌面提示卡片层次更分明。
- 卡片/边框/搜索框对比加强；保留青绿品牌色，不改交互逻辑。
