## 1. 目标与范围

本 Demo 用于在 P3 概要设计阶段预览 FolderHub 的桌面主组件布局、左侧分类/右侧文件夹列表、搜索、文件夹记录管理入口、托盘入口及独立文件夹卡片的用户可见行为。它是交互讨论原型，不是可部署产品，不替代 SRS、概要设计、详细设计或验收用例。

## 2. 运行方式

无需安装依赖。使用 Windows / macOS / Linux 浏览器直接打开：

`current/index.html`

建议使用最新版 Microsoft Edge 或 Chrome。所有交互数据仅保存在当前页面内存中，刷新页面后恢复演示样例，不会读写真实文件系统或调用 Windows 资源管理器。

## 3. 已实现交互

- 分类切换；分类为平级列表。
- 按真实名称/别名进行不区分大小写的包含搜索，动态过滤。
- 添加/编辑文件夹记录；支持多分类关联。
- 同一路径重复登记检查（演示级字符串比较，不代表最终路径规范化算法）。
- 单击选中、双击打开动作模拟、右键菜单打开/编辑/固定/删除。
- 独立卡片固定/取消固定；卡片可拖动、独立锁定。
- 主组件隐藏与托盘菜单重新打开。
- 设置面板：主组件位置锁定模拟、全局退出后保留卡片开关、背景透明度滑块。
- 删除文件夹记录前提示不会删除磁盘真实目录。
