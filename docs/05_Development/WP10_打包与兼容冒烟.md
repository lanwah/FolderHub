## 1. 交付物

| 项 | 路径 | 说明 |
|---|---|---|
| 统一版本 | `Directory.Build.props` | App/CardHost 共用 `0.1.0` |
| 旁置 CardHost | `FolderHub.App.csproj` `CopyCardHostBesideApp` | 构建后与 App 同目录，满足 sibling 启动 |
| 发布 | `packaging/Publish-FolderHub.ps1` | 合并双 exe 到 `artifacts/publish/<rid>/` + `package-manifest.json` |
| 安装/升级 | `packaging/Install-FolderHub.ps1` | 默认 `%LocalAppData%\FolderHub\app\`；升级先清空 `app\` 再复制；保留数据根；`-BackupDatabase` 含 WAL/SHM |
| 卸载 | `packaging/Uninstall-FolderHub.ps1` | 默认删二进制，并移除指向本次 InstallDir 的 HKCU Run；`-RemoveUserData` 才清库 |
| 兼容冒烟 | `packaging/Invoke-CompatSmoke.ps1` | 布局校验 + 本机 OS 矩阵标记；Server 行默认 `NOT_RUN` |

## 2. 布局约定

```text
%LocalAppData%\FolderHub\
  folderhub.db              # 用户数据（升级保留）
  install-manifest.json     # 安装记录
  backups\                  # 可选 DB 备份
  app\                      # 二进制安装根
    FolderHub.App.exe
    FolderHub.CardHost.exe
    package-manifest.json
    …
```

- 开发运行：`dotnet run --project src/FolderHub.App`（Build 后 CardHost 已复制到 App 输出目录）。
- 发布默认：framework-dependent `win-x64`（需 .NET 8 Desktop Runtime）；`-SelfContained` 可无 Runtime 冒烟。

## 3. 常用命令

```powershell
# 发布
.\packaging\Publish-FolderHub.ps1

# 本机安装（可选备份库）
.\packaging\Install-FolderHub.ps1 -SourceDir .\artifacts\publish\win-x64 -BackupDatabase

# 兼容冒烟（可加 -LaunchAppSmoke）
.\packaging\Invoke-CompatSmoke.ps1 -PublishDir .\artifacts\publish\win-x64

# 卸载二进制（保留数据）
.\packaging\Uninstall-FolderHub.ps1
```

## 5. NFR-001 / RISK-001 说明

- 目标范围仍为 Win10 22H2 / Win11 x64 + Server 2012+ 单用户 GUI/Desktop Experience。
- WP10 只建立**安装/升级骨架**与**本机抽检**；Server 逐版本义务不因本机 PASS 而解除。
