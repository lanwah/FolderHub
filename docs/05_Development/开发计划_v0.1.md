## 2. 技术假定（开工默认）

| 项 | 假定 |
|---|---|
| UI | WPF |
| 运行时 | .NET 8（`net8.0-windows`） |
| 进程 | `FolderHub.App`（Main）+ `FolderHub.CardHost` |
| 持久化 | SQLite，`%LocalAppData%\FolderHub\` |
| IPC | Named Pipes；首版即带 DACL/会话隔离骨架（ADR-036） |
| 写入权 | 遵守 ADR-035 |
| 恢复 | 遵守 ADR-037 / ADR-038 |
| 主 UI 策略 | 先普通窗口对齐 Demo；壁纸层（UIR-001）单独 spike |
| OS 矩阵 | 开发机以当前 Win11 为主；Server 2012+ 兼容性（NFR-001）后置抽检 |

> 若后续改回 .NET Framework 4.8，仅影响目标框架与部分 API，模块边界保持不变。

### 3.1 WP2～WP10 推进节奏

每个工作包按以下三步推进，完成一步再进入下一步：

1. **实现**：完成该 WP 交付与可验证验收项。
2. **审核**：用户审核阶段成果；有问题则回退修正，通过后再继续。
3. **更新文档并提交**：同步开发计划/相关台账状态后，按仓库序号规范提交改动。

## 4. 仓库结构

```text
src/
  FolderHub.sln
  FolderHub.Domain/           # 纯领域规则，无 UI/IO
  FolderHub.UseCases/         # 用例编排（避免与 WPF Application 命名冲突）
  FolderHub.Infrastructure/   # SQLite、Named Pipes、Shell
  FolderHub.App/              # Main WPF
  FolderHub.CardHost/         # CardHost WPF
tests/
  FolderHub.Domain.Tests/
  FolderHub.Infrastructure.Tests/
docs/
  design-demo/                # 交互参考（已评审）
  05_Development/             # 本计划与工程笔记
```

## 5. 安全与发布约束（保留）
